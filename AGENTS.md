# Repository instructions

- Never commit a private AmazingTalker ICS URL, calendar token, Home Assistant access token, personal name, private host/IP address, or household entity ID.
- Run every validation documented in `README.md` after changing the Blueprint, tests, workflow, or documentation.
- Keep all existing Blueprint input keys backward compatible.
- Every newly added Blueprint input must have a default so existing automations continue to load.
- Do not push while any required test or validation is failing.
- Use only official Home Assistant or Music Assistant documentation/source as technical authority.
